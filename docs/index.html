开始使用

一分钟安装

Arch Linux 用户可以直接从 AUR 安装。程序不会自动修改你的 niri 配置。

查看其他安装方式↗
terminal
❯ paru -S niri-pimg

添加到 niri 配置：

Mod+Shift+S {
    spawn "niri-pimg";
}

快速上手

操作自然，快捷直接

Wheel调整大小
E切换编辑
Ctrl C复制图片

Esc退出或关闭
